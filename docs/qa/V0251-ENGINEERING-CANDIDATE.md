## Candidate status before Windows CI

- The renderer does not grant permissions. Projects are still local; File → New Chat and View → Search Conversations retain the keyboard shortcuts. Aster_obsidian retains the existing local implementation. The baseline Sandbox receipt is not an installed test of the new candidate.
- A fresh monthly policy needs native approval, including on upgrade. The existing 31-day billing conversion profile is reviewed separately in Providers; charges and unresolved reservations never disappear at rollover. The hard cap is Aster's own conservative account ledger, not a promise about external use, exchange rates, or the Meta invoice. Reconciliation remains a separate native action. The composer shows the highest currently reached warning, or the hard stop; if one settled charge crosses both warning levels, it shows the second one.
- PASS (cloud Linux, Node 24.22.3): TypeScript check, all 228 frontend tests, and Vite production renderer build. The dictation tests exercise the real JavaScript IPC adapter against a simulated Tauri host; no audio, microphone, or network was used by those tests.
- PASS (cloud Linux, Rust 1.97.0, isolated harnesses): 34 budget/private-store tests, 47 compaction contract tests, 15 history/processed-history tests, and the separate opt-in compaction benchmark. The 6,615,899-byte, 36-turn synthetic payload took 28.3 ms median over 11 trials for local projection, validation, serialization and threshold decision; this is not Meta or end-to-end latency. Compaction fixtures also passed strict linting for the Windows MSVC target. Applying the new history index does not lift the legacy conversation limits.
- NOT RUN: Windows decoder and extracted-package audio probes and installed Windows acceptance on this source. The Linux cross-target attempt stopped in `aws-lc-sys`'s native dependency build; it is not Windows source evidence. Use the original five-job Windows workflow with the draft's exact tested commit (not the base CI).
- **Live compaction remains disabled.** The candidate includes reproducible synthetic preflight/prefix/rebuild/recovery tests and strict validation of the hypothetical terminal result, not a transport or durable 4-GiB migration. Legacy sessions still use the existing route and limits. Do not submit real keys or treat the draft as a deployment candidate. The [full-window contract](V026-AUTOCOMPACTION-CONTRACT.md) records the independent gates.
