## Baseline findings, not root-cause claims

Reviewed baseline is main `d8b9422eab83526a67bd16a23fbb0d029870d709`, with v0.2.3 runtime bytes inherited from `54c64e4`. The source already sets an opaque dark process-local WebView2 background before Tauri, dark native configuration and early dark HTML/CSS; the parent window starts hidden. Its one-shot reveal state does not intentionally hide/show twice. The fixed six/ten-second setup timers are not evidence of a +2/+5-second post-visibility source timer.

React waits for initial image load/error plus two animation-frame callbacks; that proves neither decoded images nor a presented native frame. Independent status/history hydration and layout are possible events to measure, not demonstrated causes. A hidden parent HWND does not prove the WebView2 controller's `IsVisible` state. The locked native runtime also establishes controller background during and after creation; blanket assertions that Tauri necessarily paints white first are unsupported.

## Stage C: causal decision and narrow patch

| Correlation | Investigate next | What does not establish a fix |
| --- | --- | --- |
| New navigation/document lifecycle at flash | Identify initiator and prevent only the unintended navigation or remount; preserve startup failure visibility. | Removing StrictMode or adding a sleep without a demonstrated initiator. |
| Controller/process failure or replacement | Fix the observed controller lifetime/recovery boundary; assess compatible upstream correction independently. | Hiding failure or switching GPU/runtime/security settings speculatively. |
| Parent paint/resize/theme transition, no document event | Inspect native background/WM_ERASEBKGND and controller presentation at that boundary. | Repeated hide/show or forced repaint masking an unknown cause. |
| Hydration/asset/layout transition only | Fix demonstrated full-surface repaint/remount/decode ordering while retaining all guards. | Treating rAF, image load or a CSS-only mock as native presentation proof. |
| No measured correlation | Improve narrowly missing observations and keep cause OPEN. | Declaring delayed presentation successful because source tests pass. |

A proposed narrow correction updates SPEC-0006/TM-032/its tests before code, then is evaluated against identical observation windows. Initial latency may remain a UX trade-off but is not the cure acceptance condition.
