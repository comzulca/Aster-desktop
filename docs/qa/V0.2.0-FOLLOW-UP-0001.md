## Scope controls for v0.2.0

These entries are tracked **DEFERRED FOR REVIEW**, not hidden, deleted, executed or automatically waived. Existing granular NOT RUN and historical FAIL evidence stays intact. Existing automatic PASS results keep their original source, command and UTC. Do not globally mark compound T-028/T-030/T-031/T-034/T-039/T-040/T-041 or all phase gates PASS from a category statement.

No feature is activated by this document. Before any diagnostic, provider, file-publication or persistence behavior changes, update specification, threats, ADR, negative test and exact-source evidence together. Only newly reviewed explicit authority can permit paid live tests, project disclosure, consequential file operations, a disposable power-loss environment or production publication. Shell/web/MCP/arbitrary endpoints, persistent chat history, signing and external distribution are still v0.1.0 non-goals; this future-review decision does not request their implementation. A separately requested production release needs its own exact-binary safety, licensing, signature and promotion decision.
