# ADR-0017 — single zoom owner and dark native startup surfaces

Date: 3 October 2026. Status: implemented; source-bound engineering qualification complete, installed/native verification pending. Scope: SPEC-0004, UX-012/013, NFR-007, SEC-025, TM-026, AC-061..064, T-071..074. Evidence: LOCAL-V022-0001 and CI-V022-0001; retained local full-suite block is not relabelled PASS.

Reuse the renderer's bounded presentation scale for all zoom gestures. A non-passive deliberate Ctrl-wheel handler cancels native browser zoom and invokes the same guarded action path as menus/keys. No WebView zoom API, plugin, IPC or host permission is added. Leave ordinary scrolling alone; reject malformed and modifier-conflicting input. Set the supported locked Tauri zoom-hotkeys setting false, so browser zoom cannot independently accumulate. Keep caption/layout scale behaviour already tested in v0.2.1.

Render the percentage as a non-interactive fixed top-right overlay outside the scaled shell. Use one resettable 1,000-ms timer after the latest admitted gesture, including reset/bound-edge feedback; cleanup on unmount and do not steal focus. Default 100% is hidden until a deliberate zoom action. No history/export/logging or persisted zoom/notice state.

The v0.2.1 CSS canvas is dark, but native window/WebView background was unspecified. Owner observes a white flash at 3–5 seconds on every idle launch; no corresponding source timer/reload was found. Apply explicit matching opaque dark native/WebView background and dark window theme; paint the HTML/body/root before module load using a local external stylesheet. Preserve CSP and trust guards; no unsafe-inline policy relaxation, GPU disabling, ESET bypass, arbitrary browser arguments or delayed/hidden error surface. These changes address known unpainted/default-colour exposure, not independently proven causation. Repeated owner-installed startup observation is the final native regression criterion.

Primary references reviewed 3 October 2026: [Tauri background colour](https://v2.tauri.app/reference/config/#backgroundcolor), [Tauri theme](https://v2.tauri.app/reference/config/#theme), [Tauri zoom hotkeys](https://v2.tauri.app/reference/config/#zoomhotkeysenabled), [MDN wheel event](https://developer.mozilla.org/en-US/docs/Web/API/Element/wheel_event). Verify these against locked Tauri source and package, not documentation alone.
