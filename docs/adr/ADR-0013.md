The provided test file was read only by an isolated diagnostic process; it is not imported by Aster, copied to its store, included in evidence or a native credential acceptance result. The catalogue observation proves neither generation rights nor legal/financial eligibility. No new endpoint is registered in the app.

Accepted for implementation, 2026-10-02. Use fixed target AsterDesktop/MetaModelAPI/v1 in Windows Credential Manager. Accept only bounded documented direct Model API key syntax; syntax is not entitlement. Native owner-window entry/delete confirmation and zeroised buffers; no key bytes through WebView, IPC, prompts, `.env`, logs, builds or CI. Never read/reuse/rename/delete the historical NVIDIA object during this migration. Synthetic diagnostic targets and fake keys remain isolated.
