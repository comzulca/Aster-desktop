# ADR-0011 — Fixed Meta Chat Completions

Accepted for implementation, 2026-10-02. Continue the existing messages/stream seam using the fixed Meta HTTPS Chat Completions route. Use one host-owned developer instruction, allowed Contributor reasoning efforts, max_completion_tokens=8192, n=1, store=false and stream_options.include_usage. No tools or arbitrary parameter/origin override. Dispatch the native-reviewed allocation, not a rebuilt equivalent. Return structured visible terminal status plus independently validated usage/dispatch certainty. Distinguish truncation/refusal from completion and cancellation from financial settlement. Responses/other protocols and private reasoning continuation are not admitted. Fixtures do not prove live entitlement.
