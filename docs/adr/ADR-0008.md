# ADR-0008 — coordinated locked Tauri dependency update and minor-pair guard

Date: 2026-10-01 UTC. Status: accepted for a reviewed dependency candidate; joint validation/package NOT RUN. Trace: NFR-003 / SEC-009 / TM-011 / AC-019 / T-037. Existing runtime authority, schemas, credential custody and workspace flags remain unchanged.

The owner explicitly selected one compatible coordinated update rather than independently merging incompatible Rust/API candidates, and authorized closing PRs superseded by its verified integration. Keep Vitest/Vite independent; do not auto-close an issue or close redundant PRs before exact changes are incorporated and all gates pass.

PR17's authenticated lock resolves tauri2.12.1/dialog2.8.0/build2.7.1/runtime2.12.1 and supersedes the older Rust/build targets in PR16/18. Pair it with API2.12.0 and CLI2.12.0 from PR20/21. Inventory every resolver/transitive difference; do not silently downgrade or broadly update unrelated packages. Source/check mocks do not prove installer compatibility. The unchanged unsigned build command must run without ignore_version_mismatches/signing/bypass flags.

Extend the existing read-only unsigned engineering packaging job to `pull_request` runs as well as its existing main push/manual runs, keeping dependencies, budgets, contents:read permissions, hash/manifest/NotSigned checks and no-sign command unchanged. This establishes actual bundling compatibility before an update is integrated, not merely after merge. The exact checked synthetic-merge revision/tree must be authenticated against its PR head/base; it is not a main release or manual acceptance. Do not execute downloaded installers, publish a release, alter repository rules/bypass actors or close superseded PRs based on source checks alone. Root waits for this independent packaging job even though existing branch protection names three checks. New-source main packaging and final-artifact manual selection remain separately bound.

Primary [Tauri dependency guidance](https://v2.tauri.app/develop/updating-dependencies/) requires JavaScript API and Rust tauri major/minor alignment; [installed CLI build code](https://github.com/tauri-apps/tauri/blob/tauri-cli-v2.11.5/crates/tauri-cli/src/build.rs) enforces the check before bundling. These were inspected 2026-10-01 UTC. Add a standard-library read-only source-policy guard over fixed bounded package.json/pnpm-lock.yaml/Cargo.toml/Cargo.lock inputs, resolving the exact root-importer API lock version and unique tauri Cargo package. Deny malformed/ambiguous/missing versions or mismatched major/minor; include pure self-test positives/negatives. No package installation, arbitrary command/path, mutation or network occurs in the guard. Unknown lock layout fails closed rather than guessing. Frozen package installation and locked Cargo checks remain separate.

Current main tauri2.11.6 already patches [GHSA-w28w-mhc8-qvjv](https://github.com/tauri-apps/tauri/security/advisories/GHSA-w28w-mhc8-qvjv); do not label it exposed based on repeated 2.12 release notes. Prior Rust candidates' logs had three allowed warnings, not zero; the historical baseline had eight. Rerun current audit and bind exact warning/SBOM/license output to the final candidate. Upstream Apache2.0 OR MIT selection and actual transitive payload/notices remain independent of the owner proprietary LICENSE decision.

Reconcile fresh source/ledger evidence after the update; do not inherit old 80/90 Rust, 23 frontend or prior installer observations as current tests. All four file capability flags stay false and real NVIDIA credential stays untouched. Exactly two final-artifact plain-text live canaries remain reserved. No guest account, VM, OS protection/security/trust change or elevation is included.
