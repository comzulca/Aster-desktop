# ADR-0010 — Meta-only protocol 3

Accepted for implementation, 2026-10-02. SPEC-0002 replaces the active NVIDIA/two-model protocol-2 registry with exactly Meta Model API / muse-spark-1.3-contributor. Host and renderer reject incompatible versions, unknown fields and all alternate pair/origin/tier IDs. Remove old project and credential IPC registrations, rather than hide invocable permissions. All four project flags are false. Preserve old secrets and publication/recovery evidence; no historical conversation import. Consequence: old-provider tests are antecedents, and compatibility/denial fixtures must be rerun on v0.2.0.
