# ADR-0012 — Contributor data admission

Accepted for implementation, 2026-10-02. Contributor's training/content conditions require a public-eligible/synthetic-only initial profile. No project, attachment, proposal or file-apply route is available. The user's classification is bounded intent, not proof or permission to override a host denial. Re-admit all prior prompts and answers and review the complete exact request natively before each dispatch. Unknown/private/personal/sensitive/confidential classes and known secret/identifying patterns deny locally. Safe filters are not a universal confidentiality detector. Native terms/eligibility acknowledgement is distinct from per-request review, account entitlement, and live test authority. The legal revision observed is 2 October 2026, superseding the plan's date.
