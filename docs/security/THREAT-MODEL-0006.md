Native key entry → Meta Credential Manager target → fixed host verifier → non-secret generation-bound status → composer admission.

Native GitHub connection intent → fixed GitHub App device endpoints → trusted browser/account authorisation → native-only access/refresh credentials → authenticated account and selected installation/repository IDs → bounded host proposals → separate exact native confirmation → host revalidation/dispatch → verified terminal outcome. No token, device-code secret, generic URL or approval capability is a model tool.

Editor/import/generated package → bounded parse and immutable revision → reviewed catalogue entry → selected inert instruction text. Only the separately implemented built-in GitHub broker can execute tools. Third-party scripts and MCP are deferred by the owner's later clarification.

Personalization editor → closed bounded host intent → separate encrypted current-user local domain → local UI only. This domain has no edge to Meta, context summaries, package generation, GitHub payloads, logs, exports or restored grant state.

Eligible conversation/processed media → explicit bounded context selection and summary admission → host-authored lower-trust summary + recent context → separately reviewed Meta request. Full local display history is not silently replaced, and a summary never revives native PDF originals or disclosure rights.
