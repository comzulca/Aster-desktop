| Edit | `Undo` — Ctrl+Z; `Redo` — Ctrl+Y; separator; `Cut` — Ctrl+X; `Copy` — Ctrl+C; `Paste` — Ctrl+V; `Delete`; separator; `Select All` — Ctrl+A; separator; `Settings…` — Ctrl+, | Standard selection-aware editing of the current editable field, primarily the composer; never rewrite saved user/assistant messages or native secret fields.
