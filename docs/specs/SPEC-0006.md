Safe external conversion to PDF remains the owner decision. Native PDFs are sent from temporary copies; only processed pages and responses persist, and another complete native reading requires reattachment. Do not change these contracts implicitly while adding compaction.

The owner's latest clarification limits executable plugins to the built-in, reviewed GitHub connector. General script/hooks/process execution, third-party MCP servers, package dependency installers, public marketplaces and unrelated services are out of v0.2.4. The editor may represent portable package content but must mark unsupported execution inactive. Account authorisation never permits private/personal/confidential repository content to be sent to the Contributor model.
