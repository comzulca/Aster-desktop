# SPEC-0009 — v0.2.5 local dictation and chat readiness

Baseline: main `df3143971ede2c45030b4c46ac84afef129e8793`. The owner supplied a composer reference with the microphone between the reasoning selector and Send. The requested deliverable is a Windows x64 engineering installer. The owner authorized a public branch, PR and candidate CI. The supplied provider credential stays outside source, CI and artifacts.

| Requirement | Acceptance and defensive test |
| --- | --- |
| FR-038 / AC-096 / T-106 | Starting dictation requires an explicit user action and native consent. Capture ends on stop, cancellation or a hard timeout. One session owns the input device. Closing the window releases it. |
| SEC-040 / AC-097 / T-107 | Audio stays local. Run the fixed whisper.cpp CPU decoder with its packaged multilingual model. The caller cannot specify executable, model, file path or CLI options. Verify the native distribution and model, including their licenses, before packaging. An invalid or missing asset blocks dictation. |
| UX-022 / AC-098 / T-108 | Render the recording control in the supplied position with accessible start/stop and status. Put recognized words into the editable draft. Retain typed text, enforce its byte bound, invalidate prior classification after editing and discard cancelled or stale results. Sending remains a separate deliberate action. |
| FR-039 / AC-099 / T-109 | After a credential write or external change, display the current host state and the next actionable prerequisite. Distinguish missing credentials, invalid credentials, provider failure, pending terms, budget and draft classification. Authentication failures convey bounded actionable information. Preserve native approval, spending limits and eligibility checks. |
| NFR-013 / AC-100 / T-110 | Exercise contradictory and stale UI/IPC results, provider errors, resource substitution and speech on a known fixture. Run existing source, Windows and installer gates. Record synthetic live Meta evidence separately from an installed GUI journey. |

The microphone and model handle potentially personal content. Neither audio nor an unsubmitted draft grants permission for disclosure. Keep capture out of the webview and the provider transport. Validate the packaged decoder payload independently of the installer manifest. Treat malformed or late output as a failed dictation. A failed capture or provider call must leave the draft usable.
