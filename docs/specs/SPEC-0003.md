## Implementation boundaries

Window actions are intent, not grants: a bounded typed bridge delegates only to the calling authenticated `main` window and existing Rust state. No wildcard window/core permission. The custom caption row is needed solely for the requested flag placement; title controls must function, preserve resize/double-click/drag affordances and have accessible names. OS close requests follow the same guarded quit route, not a hidden bypass of draft/busy checks. Native secret/disclosure dialogues cannot be displaced by conflicting actions.

Clipboard operates only on deliberate local user edit actions. Do not add a native clipboard watcher, global capture, plugin or background reader. Preserve original selection/caret when menus take focus. Keep Undo/Redo local and bounded; define support honestly and test handler results. Render all conversation/help/status content as inert text. Search is local visible-content/title search, not protected-store scanning or web retrieval. Zoom is bounded local presentation and 100% reset; not a text/body mutation. Help and System Status are bundled/offline and reflect unavailable/unverified configuration truthfully.

History navigation retains existing host validation/busy guards. Per-chat drafts are display-only, bounded by the existing 32-KiB UTF-8 message ceiling and 128-conversation profile; cache only memory during this process, no restored approval/classification/financial authority. Ending the process discards this ephemeral cache only after explicit default-cancel review if nonempty; persisted conversations, credentials, pending charges and old journals are unaffected. No new export/import/compaction or destructive tests.
