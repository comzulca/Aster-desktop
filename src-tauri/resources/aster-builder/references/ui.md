# Default visual specification
Use assets/default-ui.jpg (1917 x 1137; SHA-256 b95163a411529b8608461dda4faeacab3f09c6cde090c3b1d72092bf0a7c4887) when no other user interface is given. Recreate its dark desktop composition: a roughly 44 px top title bar; a roughly 345 px left rail with branding, new-chat/search, conversation history, projects and settings; an open central canvas with an honest empty state and two focused actions; a compact connection/status region; and a bottom-centered rounded composer with attachment, model/profile selector and send action. Adapt to smaller windows without clipping the composer or hiding status.

Use accessible contrast, named controls, visible focus, keyboard navigation, screen-reader-friendly streamed updates, and localized user-facing copy. Display unavailable controls as unavailable. Provider, model, key, local-storage and web status must reflect implemented capabilities, not the example's NVIDIA, Kimi-K3, local-first, or Not checked text. Replace Aster logo/wordmark for other products unless the user confirms that product identity. Treat the screenshot as a layout reference and acceptance fixture, not as backend evidence.

Check empty, loading, ready, disconnected, sending, cancelled, tool proposal, rejected and recovery states. Verify the default UI at 1917 x 1137 and a compact 1366 x 768 viewport; test keyboard and status behavior in an actual rendered view when available. Use structural and accessible-state assertions plus a reviewed visual snapshot; do not equate pixel identity across operating systems with security or functional correctness.
